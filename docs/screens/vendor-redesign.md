# Vendor Redesign Direction

## Vendor Shell

- Persistent bottom navigation with Orders, Products, Insights, and Profile
- Same Luqmah theme language as customer shell
- Slightly denser operational layout without changing the brand identity

## Orders Screen

- Utility-first header and queue summary
- Segmented control for active/history views
- Structured cards with status chips and concise metadata

## Order Details Screen

- Clear customer identity block
- Readable itemized order breakdown
- Inline status management

## Products Screen

- Focus on inventory clarity and add-item flow
- Same card and spacing system as customer UI

## Insights And Profile

- Keep operational surfaces on the same brand foundation
- Avoid dashboard drift into a separate visual language
