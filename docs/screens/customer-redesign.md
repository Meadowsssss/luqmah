# Customer Redesign Direction

## Customer Shell

- Persistent bottom navigation with Browse, Cart, and Settings
- Stable shell-driven navigation instead of page replacement
- Shared Luqmah theme tokens throughout

## Restaurants Screen

- Deep green hero container for brand recognition
- Structured restaurant cards with consistent image crops
- Warm-coral highlights for ratings and key accents

## Menu Screen

- Large title and image-led header
- Category chips for quick filtering
- Item cards with clear price/action hierarchy

## Cart Screen

- Utility-first layout
- Strong total row and compact quantity controls
- Clear empty state and lightweight order confirmation

## Settings Screen

- Simple account summary
- Lightweight session actions
- Same cards and spacing system as primary product pages
